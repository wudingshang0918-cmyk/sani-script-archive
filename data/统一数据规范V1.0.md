## 二、统一记录字段（各资料映射）

**通用字段**：
```
source      资料编号（D1/D2/D3/D4）
id          资料内序号（词典=SN号 / 400句=句号 / 识字本=章-词序 / 丧家经=页栏序）
sani_ipa    撒尼语读音（IPA，统一为数字调值制：55/44/33/22/21）
han         汉文（释义/直译/意译）
zh_note     汉字注音（400句资料独有）
yiwen_img   彝文字形图（文件路径，替代不可 OCR 的文字）
page_ref    原书页码（可回溯）
```

**四类记录**：

| 类型 | 字段组合 | 来源 |
|---|---|---|
| **词条** | sani_ipa + han + page_ref | D1、D3 |
| **句子** | sani_ipa + han（汉语句）+ 直译 + zh_note + audio | D2 |
| **经行** | yiwen_img + sani_ipa + 直译 + 意译 + page_ref | D4 |
| **字形** | yiwen_img + code（形码）+ han | R1、R2 |
